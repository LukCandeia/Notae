# Ajuda rápida

[[00 - Início|Voltar ao início]] · [[Comece aqui|Primeiros passos]]

## Criar assuntos

No topo do início, use **Nova disciplina** ou **Novo estudo independente**. Informe o nome e clique em **Criar**. Não é preciso editar código.

Disciplinas recebem **Anotações**, **Materiais**, **Materiais/Arquivos** e **Trabalhos e provas**. Estudos independentes recebem **Anotações**, **Práticas**, **Materiais** e **Materiais/Arquivos**.

O nome da pasta e o da página principal devem corresponder, por exemplo `Linux/Linux.md`. Use os comandos para criar a estrutura. Se renomear manualmente um assunto, renomeie tanto a pasta quanto a página e revise os links de adicionar conteúdo nela.

Nomes repetidos na mesma categoria são recusados. Para repetir uma matéria em outro período sem misturar conteúdos, inclua o semestre no nome, como **Matéria de exemplo - 2027.1**.

## Adicionar conteúdo

1. Clique em **Adicionar conteúdo**.
2. Escolha uma disciplina ou estudo, ou deixe **Guardar para depois**.
3. Informe um título. Cole texto ou links e, se quiser, selecione ou arraste arquivos.
4. Clique em **Guardar conteúdo**.

Só o título é obrigatório. Ao abrir o formulário dentro da página ou de uma nota de um assunto, o destino já vem selecionado.

Texto sem anexos ou links é classificado como anotação. Links e arquivos sugerem material. Em **Mais opções → Organizar como**, você escolhe a classificação; exercícios de estudos independentes vão para **Práticas**. Trabalhos e provas são opções de disciplinas ou de notas ainda sem destino.

Cada nota nova ganha um link de volta à página do assunto. Títulos repetidos recebem números, sem substituir notas existentes.

## Guardar para depois

As notas sem destino ficam em [[Para organizar/Caixa de entrada|Para organizar]]. Para movê-las depois, abra a nota e procure **Notaê: Escolher destino desta nota** na paleta de comandos. No computador, o menu de contexto da nota também oferece **Escolher destino**.

Escolha o assunto e, se necessário, ajuste a classificação. As cópias dos anexos em **Para organizar/Arquivos** também são organizadas.

## Anexos

Arquivos importados são copiados para **Materiais/Arquivos** no assunto escolhido. Os originais externos são preservados. Arquivos com o mesmo nome e conteúdo na pasta de destino são reutilizados; arquivos diferentes com o mesmo nome recebem numeração.

PDFs, imagens e mídias compatíveis são incorporados à nota. A reprodução depende do formato e da plataforma. Os demais arquivos ficam como links para abrir. O modelo não transforma PDFs em resumos nem usa IA para classificar o conteúdo.

Arquivos inseridos diretamente nas notas também podem ser organizados quando são salvos inicialmente em **Para organizar/Arquivos**, conforme a configuração deste modelo. Não são movidos anexos que já estão em outras pastas.

## Organização pelo título, opcional

Uma nota em **Para organizar** pode ser organizada com um nome como **Linux - Exercício - Permissões**, usando o nome completo de um assunto já criado. Se houver uma disciplina e um estudo com o mesmo nome, use o formulário para escolher o destino.

## Atalhos e controles

- **Ctrl+Shift+N / Cmd+Shift+N:** adicionar conteúdo, se o atalho não estiver em conflito com outro comando.
- **Paleta → Notaê: Abrir início dos estudos:** abrir a página principal.
- **Paleta → Notaê: Nova disciplina:** criar uma matéria.
- **Paleta → Notaê: Novo estudo independente:** criar um tema.
- **Paleta → Notaê: Adicionar material:** abrir o formulário com a classificação de material.

Os botões funcionam na visualização de leitura e nas áreas renderizadas da edição. Se estiver vendo o texto do link, alterne a nota para leitura.

Se as listas aparecerem como blocos de código ou não responderem, confira se **Notaê** está ativado. O estilo dos botões usa **Configurações → Aparência → Trechos CSS → faculdade**. Depois de atualizar o código do complemento, desative e ative apenas ele.

## O que não está incluído

Não há sincronização com celular, integração com calendários ou notificações. Os arquivos ficam no aparelho em que o vault foi aberto. A versão Android ainda precisa de teste manual; não há garantia de comportamento idêntico para importação e reprodução de todos os tipos de arquivo.
